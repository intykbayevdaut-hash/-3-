CyberHub
A lightweight, modern, self-contained dashboard and terminal-style productivity utility designed for quick deployment on GitHub Pages.
Features
100% Self-Contained: Single HTML file with embedded CSS and modern JavaScript. No complex build steps or dependencies.
Interactive Terminal UI: Built-in command interpreter and quick note logger.
Responsive & Dark Mode: Sleek futuristic aesthetic optimized for all screens.
Quick Start
Clone the repository or download the files.
Enable GitHub Pages in your repository settings (select branch `main` / `root`).
Access your live web app instantly!
